An AI agent selected one unforgettable GTA 6 launch-day gameplay moment: a shark mauling a scuba diver live on stream. It cut the scene into a vertical Short, added a make.fun pitch at the end, and published the finished video publicly on YouTube. This repository's program copies `VIDEO.json`, which names that video, into the output directory.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/VIDEO.json
```
